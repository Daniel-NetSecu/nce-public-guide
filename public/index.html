A METHOD, NOT A TRANSCRIPT

三步背诵：原文留在你的教材里

  1. 读懂并分成三块。打开你合法取得的教材，按意义转折自己划为 A / B / C 三块；不必等长。每块只在纸上记 2–4 个提示词。
  2. 遮住原文，逐块回忆。读 A 块，合上书复述，再对照检查；B、C 同样操作。卡住时只看提示词，不在本站粘贴课文。
  3. 串联并间隔复习。按 A → B → C 串起来，尤其练习块与块之间的衔接。今天、明天、三天后再各试一次，回看漏掉的连接词与时态。

这是通用学习方法，不算作某课原创内容已完成。本站练习例句不是教材原句，也不能替代原文。
