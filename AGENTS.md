# Public guide maintenance

- Work only within this new project. Never import another Git history or change any other repository.
- Publish only public/ and its exact allowlist in scripts/test.mjs. Keep the repository submission allowlist in README.md.
- Never add textbook passages, translations, full paraphrases, lecture files, audio, subtitles, credentials or local private paths.
- Course metadata is identification only. Independently author all explanations, examples, questions and answers. Do not make cloze tests from textbook sentences.
- Mark ready only with real vocabulary/exercises. Generic memorization advice does not count as lesson coverage.
- Read existing state before editing workflow/configuration. No remote publishing without the owner task.
- Preserve link provenance. Fetch directory pages only, extract observed href values; never guess per-lesson links or fetch full passages.
- Validate node scripts/test.mjs; review content manually as pattern checks cannot establish originality or legal clearance.
- Keep UI dependency-free, keyboard-accessible, mobile-friendly; do not add analytics or third-party embeds.
